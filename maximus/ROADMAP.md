# Marketing suite roadmap

Legend: [x] done and live-ready · [~] started · [ ] not started · 🔌 needs a connection or approval from the owner

## 1. Ads to funnels (Marketing → Ads)
- [x] Ads section under Marketing, one place per product funnel
- [x] AI plans the ads: objective, audience, budget, 4 different ad ideas (video and image), copy, headlines, buttons
- [x] Video shot lists with hook, voiceover and on-screen text; picture briefs
- [x] Automatic Facebook-rules checker (medical claims, personal attributes, income/recruitment claims, guarantees, results, before/after, unsafe ingredients) running while the AI writes and while the seller edits
- [x] NAFDAC number required for food, supplement and herbal products
- [x] Tagged links: every lead and order shows which ad brought it
- [x] Before-you-run checklist (real photos, dollar card, VAT note)
- [ ] 🔌 Connect Facebook and publish the ads for the seller (needs Meta business verification and app review, then a Meta app ID and secret)
- [ ] Ad images and template videos generated by the app (needs an image/voice provider key)
- [ ] Results screen: spend, messages, orders per ad, with plain-language advice

## 2. Import a funnel from HTML
- [x] Paste or upload HTML and turn it into editable funnel sections (scripts, styles, event handlers and unsafe links removed)
- [x] Two modes: keep my layout, or rebuild beautifully with AI (keeps all real copy, pictures, links and form questions)
- [x] Start a new funnel from HTML, or import into an existing funnel (append, replace the page, or new page) with review before applying
- [ ] Import from a web address (needs a safe server-side fetcher; deferred)

## 3. Emails
- [ ] Email designer: drag and drop, AI draft, import your own HTML
- [ ] Contacts built from funnel leads and orders, with lists and unsubscribe
- [ ] Sending, one-off and sequences 🔌 (email provider: Resend via the Vercel Marketplace, plus a sending domain)

## 4. Forms and surveys
- [x] Extra questions and consent box on funnel forms
- [x] Standalone forms and multi-step surveys with their own public link (/s/…), 12 question types, required fields, consent box, redirect or thank-you message, 8 looks
- [x] AI builds a form or survey from a description
- [x] Responses inbox with counts per choice, averages, Net Promoter Score and CSV download
- [ ] Show answers branching (skip logic), and embed a form inside a funnel page

## 5. Templates
- [x] 5 funnel types, 8 looks, 10 prebuilt sections, saved sections
- [ ] Large template library by industry and goal, previewed before choosing
