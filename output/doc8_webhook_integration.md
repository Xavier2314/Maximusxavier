## Quick Reference: Make.com Terms Used in This Script

| Term | Meaning |
|------|---------|
| Scenario | A complete automation workflow in Make.com |
| Module | A single action step within a scenario |
| Trigger | The module that starts a scenario (e.g., incoming webhook) |
| Bundle | A single set of data processed in one scenario run |
| Connection | An authorized link between Make.com and an external app |
| Custom Webhook | A Make.com trigger that receives data from any external source via a URL |
| JSON Parser | A Make.com module that breaks apart JSON data into usable fields |
| Operations | The number of module executions (used for billing/plan limits) |
| Error Handler | A module path that activates when another module fails |
| Data Store | Make.com's internal database feature (not used in this scenario) |
| Router | A module that splits a scenario into multiple conditional paths |
