## Quick Reference: Make.com Concepts Used in This Script

| Term | Definition Used in Context |
|---|---|
| Scenario | The automated pipeline connecting all apps |
| Module | Each individual app action (Typeform, HubSpot, Gmail, Slack) |
| Trigger | The event that starts the scenario (new Typeform submission) |
| Instant Trigger | Fires immediately via webhook, not on a schedule |
| Webhook | Typeform "pushes" data to Make.com in real time |
| Bundle | One package of data — one form submission = one bundle |
| Scenario History | Log of every run with data and success/failure status |
| Operations | Make.com's usage unit — roughly 3–4 per lead |
| Filter | Stops the scenario if a condition isn't met (e.g. empty email) |
| Error Handler | Catches failures so the scenario doesn't fail silently |
| Router | (Referenced conceptually) Splits flow into multiple branches |
| Data Mapping | Connecting Typeform fields to HubSpot/Gmail/Slack fields |
| Connection | Authenticated link between Make.com and an external app |
